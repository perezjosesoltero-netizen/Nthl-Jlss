# Nthl Jlss

A Next.js app that answers study questions using lesson material as context.

## Getting Started

```bash
npm install
npm run dev
```

## Environment variables

Create a `.env.local` file with:

```bash
OPENAI_API_KEY=your_key_here
```

## Features

- Paste lesson content
- Ask a question
- Get a direct answer with explanation
- View context used from the lesson
